# Project background

Steve Shi's official personal Homebrew tap for distributing and updating macOS applications including MacSSH, MDWriter, Boxer, and QuickDMG.

## Goals
- Provide automated, reliable Homebrew Casks for Steve Shi's software portfolio.
- Automated checksum verification and version updates via GitHub Actions.
